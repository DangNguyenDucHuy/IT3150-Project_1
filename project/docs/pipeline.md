# Pipeline

## 1. Overview

This file describes main pipeline of the system 


## 2. Project structure

```bash
project/
|-- data/                           # Contains all the data used for and generated by the main pipeline
    |-- sources/                        # Initial input
    |-- bronze/                         # Raw data 
    |-- silver/                         # Processed data
    |-- gold/                           # Handled data which is ready for business logic
|-- docs/                           # Documentation
    |-- project_charter.docx            # Project Charter
    |-- pipeline.md                     # This file of course
|-- src/                            # Source code - Each subfolder is a partial pipeline
    |-- config/                         # Includes configs, global constants, schemas, ... of all pipelines
    |-- collector/                      # Partial pipeline - collecting data
    |-- ...
    |-- main.py                         # Main pipeline - which simply run all the partial pipelines
```


## 3. Main pipeline

### Run

```bash
cd project
python -m src.main
```


## 4. Partial pipelines

### 1. Config

```bash
project/
|-- src/
    |-- config/
        |-- [module].py                     # Each partial pipeline (module) has its specific config
        |-- ...                             
        |-- main.py                         # General configs
        |-- run.py                          # Run script - makedirs and check important env variables
```


### 2. Collector

```bash
project/
|-- data/
    |-- sources/                        # Input
    |-- bronze/                         # Output
|-- src/
    |-- config/
        |-- main.py                         # General config
        |-- collector.py                    # Specific config
    |-- collector/
        |-- youtube_collector.py            # Collect data from Youtube
        |-- ...                             # Collect data from other sources...
        |-- utils.py                        # Includes utils, helpers, ...
        |-- run.py                          # Run script - run all the collectors
```
